🧩 3D Rubik’s Cube Solver using Reinforcement Learning

This project implements a 3×3×3 Rubik’s Cube solver using Q-learning, a reinforcement learning technique that enables the model to learn optimal solving strategies through exploration and feedback.

🔍 Features

Fully interactive 3D visualization of the cube built with RaylibPy

Q-learning agent trained to find efficient solutions

Support for cube manipulation, state tracking, and reward-based training

Clean and modular Python codebase for easy understanding and experimentation

🧠 Technologies

Python · RaylibPy · Reinforcement Learning · Q-Learning · NumPy

🚀 Goal

The main objective is to explore how reinforcement learning can be applied to complex problem-solving and pattern recognition, using the Rubik’s Cube as a challenging case study.
